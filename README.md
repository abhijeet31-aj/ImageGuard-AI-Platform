🛡️ ImageGuard – AI-Powered Image Authenticity & Trust Assessment Platform

ImageGuard is an AI-powered platform developed to improve trust and transparency in e-commerce by verifying the authenticity of product images. The system leverages Artificial Intelligence, Computer Vision, and Deep Learning to detect manipulated, AI-generated, and duplicate images while analyzing metadata for signs of tampering. It generates an Image Trust Score and a comprehensive authenticity report, enabling administrators to approve or reject product images before they are published. The platform helps reduce fraudulent listings, improve customer confidence, and maintain the integrity of online marketplaces.

🚀 Key Features

- Secure User Authentication
- Product Image Upload
- AI-Based Image Authenticity Verification
- AI-Generated Image Detection
- Duplicate Image Detection
- Metadata Analysis
- Image Trust Score Generation
- Admin Dashboard
- Detailed Verification Reports
- Product Approval & Rejection System

🛠️ Tech Stack

-Frontend: React.js
-Backend: Node.js, Express.js
-AI Service: FastAPI (Python)
-Database: MongoDB
-Computer Vision: OpenCV
-Deep Learning: PyTorch
-Authentication: JWT
